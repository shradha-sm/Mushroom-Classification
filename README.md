# 🍄 Mushroom Classification

## 📌 Project Overview
This project uses Machine Learning to classify mushrooms as **Edible** or **Poisonous** based on their physical characteristics. Different classification algorithms were trained and compared to identify the most accurate model.

---

## 📂 Dataset
- Dataset: Mushroom Classification Dataset
- Target Variable:
  - Class (Edible / Poisonous)

### Features
The dataset includes various mushroom characteristics such as:
- Cap Shape
- Cap Surface
- Cap Color
- Bruises
- Odor
- Gill Attachment
- Gill Size
- Gill Color
- Stalk Shape
- Stalk Root
- Ring Type
- Spore Print Color
- Population
- Habitat
- and other categorical features.

---

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## 📊 Data Preprocessing
- Checked for missing values
- Encoded categorical variables
- Split dataset into training and testing sets
- Prepared data for machine learning models

---

## 🤖 Machine Learning Models
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree Classifier
- Random Forest Classifier

---

## 📈 Model Performance

| Model | Accuracy |
|--------|----------|
| Logistic Regression | 94.77% |
| K-Nearest Neighbors | 99.63% |
| Decision Tree | 100% |
| Random Forest | 100% |
